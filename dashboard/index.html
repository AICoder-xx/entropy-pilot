新手指南

先了解字段和启动范围，再自行决定是否实盘。教程只讲解，不保存配置、不发送订单。

跟着页面走一遍

9 步认识钱包、预算、策略、数据和停止入口。可随时跳过或关闭。

从哪里开始

  1. 准备授权。在交易所为资金账户授权独立的 API 钱包。本页填写钱包名称、被授权交易的资金账户地址、API 钱包私钥；不填写主钱包私钥。
  2. 保存本机配置。同名钱包更新，地址或私钥留空保留旧值；换资金账户请用新钱包名称。私钥以明文保存到本机 wallet.local.json，不要上传或分享。保存不代表交易所授权已经通过，启动时还会核验。
  3. 检查参数和状态。在顶部选市场查看预算。确认当前资金账户、仓位、挂单及策略启动范围。新安装默认停止；已有运行记录可能按原状态恢复，先看机器人状态。
  4. 选择策略，再决定启动。双边做市启动全部启用钱包的全部启用市场；网格仅启动所选钱包与市场。库存网格为实验性功能，尚未经过实盘测试。启动按钮会发送真实订单。
  5. 运行后看状态与成交。启动请求已提交不等于已经成功报价。若账户、授权或参数核验未通过，查看日志提示再处理。

想先熟悉运行方式，可用安装目录的 run_market_maker.bat 或 run_grid.bat 模拟盘入口；模拟成交不能还原真实排队位置。

风险预算怎么填

先选 SNDK 或 ANTH。四项金额分别作用于该市场的每个启用钱包，不是多个钱包共享一份总额。这里的市场选择也不是做市启动范围开关。

做市单侧总额
双边做市一侧整条报价梯子的 USD 名义金额；多层会拆分这笔总额，不是每层再用一份。网格每单金额另填。
最大仓位
该市场的仓位金额限制；也约束网格。它不是保证金金额，也不代表实际已持仓。
最大挂单
该市场工作挂单的金额限制；也约束网格。数值须与双侧报价和网格单笔金额兼容，保存时会校验。
会话回撤上限
相对本次启动时账户权益的下降停机阈值；也约束网格。它不保证最终亏损不会超过此值。

点击保存固定预算会关闭所选市场按权益自动放大，并把四项作为下次启动配置。运行或恢复中无法保存。没有保存就保留原配置；切换市场或自动刷新不会覆盖尚未保存的输入。

下面的“当前运行合计／上次运行合计”是只读统计，和输入框中的下次启动配置分开。不同钱包、市场的总敞口需合并考虑。此处不提供通用适合所有账户的金额。

双边做市与库存网格

双边做市

在参考价格两侧挂 Maker 限价单，根据持仓调整报价。成交可能积累仓位，不能把“双边”理解为没有方向风险。启动范围是全部启用钱包的全部启用市场。

库存网格（实验性）

实验性功能，尚未经过实盘测试。围绕锚点按价阶挂单。做多为买入建仓、卖出减仓；做空反过来。减仓单仅使用已有库存。仅启动选择的钱包与市场，可能持续积累方向性仓位。

库存网格目前仅代码可用，属于实验性功能，尚未经过实盘测试。选择网格后，面板会显示以下字段；教程不会替你切换策略。

钱包 / 市场
明确本次网格操作对象，和“查看运行”的历史记录选择分开。
库存方向
首次接管已有仓位须同向。已有网格历史后，变向须空仓、撤清挂单并完成账本确认。
网格层数
锚点两侧各自的候选层数，不保证同时出现两倍层数的挂单；库存、风险限制和价格位置会限制实际下单。
间距（bps）
相邻价阶的相对距离，100 bps = 1%。价差还需要覆盖实际费用等成本。
每单金额
每个网格订单的 USD 名义金额，受最小订单、取整、库存和风险额度约束。
锚点价格
留空由策略自动建立初始锚点；满足空仓等条件后才可重新定心，不会始终追着价格移动。

“仅保存网格参数”不启动交易。网格启动按钮会保存当前参数并提交所选钱包、市场的启动请求。

每块数据怎么看

查看运行
选择钱包、市场、模拟／实盘和策略记录，仅改变查看范围。先核对范围、截止时间及历史标签。
账户与市场快照
官方账户与行情读取结果，带更新时间。“不可用”或“—”表示未知，不能当作零持仓、零挂单或零费用。
策略历史统计
所选运行记录的历史摘要。停止后仍会保留历史盈亏和成交，不代表当前还在交易。
会话图表
只使用所选会话保存的成交。累计成交额不是收益；已实现减实际手续费不含浮盈亏、资金费和返佣，也不是账户权益曲线。缺失数据保持未知。
买卖成交分布
按已知成交金额计算比例，不是当前多空仓位比例。
持仓与挂单敞口
看现有仓位及挂单成交后的方向风险，结合对应风险上限；不要只看成交量。
挂单、成交、日志
官方最近 24 小时成交与脚本所选会话逐笔成交范围不同。日志保留原始时间；先看具体报错及对应钱包、市场。
网格账本
配对价差收益与真实库存盈亏分开。配对收益不等于账户整体盈利，不能再次叠加到真实盈亏中。

30 秒 markout 表示成交后价格变化，不是最终亏损。投影返佣尚未到账，不是已实现现金收入。

停止与常见问题

“全部安全撤单并停止”请求所有策略停止并撤销策略挂单，不等于平掉已有仓位。等待状态确认，随后在交易所核对仓位和挂单。关闭浏览器标签不等于停止后台服务或机器人。

为什么仍显示 stopping？
可能仍在撤单或核对迟到成交。查看日志和交易所状态，不要通过强杀进程、删除状态文件或重复启动来跳过对账。
为什么保存或启动按钮不能点？
查看页面提示：可能是只读预览、正在运行／恢复、钱包尚未配置，或配置读取与参数校验未通过。先处理给出的具体原因。
为什么有成交，却没有完整净收益？
成交价格、费用、资金费、未实现与返佣覆盖不同。缺失项不会自动补零；完整净收益需要对应资料齐全。
遇到 UNKNOWN、授权失败或启动失败怎么办？
先读错误和该市场日志，核对官方订单、仓位及 API 钱包授权。UNKNOWN 表示结果尚不确定，不要删除台账或盲目重发。
作者链接会自动绑定钱包吗？
不会。用户自行在官网确认邀请关系。75% 邀请返佣按 Entropy 收取的手续费份额计算，不是全部交易手续费的 75%；实际权益以官网账户页为准。
