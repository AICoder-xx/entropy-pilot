# Entropy Pilot

**Entropy 向けの両側マーケットメイク、実在庫ベースのグリッド取引、ローカルダッシュボード。**

[简体中文](../../README.md) · [English](README.en.md) · [繁體中文](README.zh-TW.md) · 日本語 · [한국어](README.ko.md)

Entropy Pilot は自分の PC で動作する Python ツールです。`io:SNDK` と `io:ANTH` に対応し、ウォレット設定、リスク予算、戦略操作、チャート、ログをローカル画面にまとめます。**現在の UI は中国語です。このページは説明書の翻訳であり、UI の日本語化を意味しません。**

> ダッシュボードの実取引開始ボタンは実際の注文を送信します。公開 CLI 設定の初期値はペーパートレードです。戦略や紹介特典による利益は保証されません。

> **在庫グリッドは実験的な機能です。実取引テストは未実施で、完了しているのはコードの実装とコードレベルのテストのみです。実取引での利用可能性が検証済みであることを意味しません。**

## 主な機能

- **両側マーケットメイク：** ALO/Maker 注文、在庫に応じた価格調整、ポジションと注文額の制限。
- **実在庫グリッド（実験的機能）：** ロング・ショートに対応。決済注文は保有在庫を減らし、ペアの利幅と口座損益を分けて記録します。コードの実装とテストのみ完了しており、実取引テストは未実施です。
- **複数ウォレット・市場：** 実行プロセスと注文・約定・復旧記録を分離します。
- **ローカル操作：** ウォレット登録、固定予算の保存、開始と安全な停止、チャートとログの確認。
- **不確定な注文の照合：** `UNKNOWN` を保持し、元の注文を確認してから次の処理を行います。
- **9 ステップのガイド：** 操作箇所を強調表示します。設定保存や注文操作を自動実行しません。

## Windows でのクイックスタート

[Git](https://git-scm.com/downloads) と [Python 3.11 以降](https://www.python.org/downloads/) をインストールしてください。Windows Python Launcher（`py`）も必要です。今回のインストール、テスト、ブラウザー操作は **Windows / Python 3.13** で確認しました。ペーパートレードに秘密鍵は不要です。実取引には資金口座と、その口座から個別に承認した API ウォレットが必要です。

PowerShell から Git と Python 3.13 をインストールすることもできます。

```powershell
winget install --id Git.Git -e --source winget
winget install --id Python.Python.3.13 -e --source winget
```

`winget` がない場合は、上記の Git と Python の公式ダウンロードリンクを利用してください。インストール後は **PowerShell を閉じて開き直し**、バージョン確認とプロジェクトのセットアップを行います。

```powershell
git --version
py -3.13 --version
git clone https://github.com/AICoder-xx/entropy-pilot.git
cd entropy-pilot
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-live.txt
.\.venv\Scripts\python.exe dashboard.py
```

**http://127.0.0.1:8765/** を開きます。仮想環境の Python を直接呼ぶため、`Activate.ps1` の実行や PowerShell 実行ポリシーの変更は不要です。ソースをダウンロードして展開し、`install.bat`、続いて `run_dashboard.bat` をダブルクリックする方法もあります。

通常モードでは設定を保存できます。新規インストールは停止状態ですが、**既存の運用ディレクトリでは保存済み状態に従って復旧する場合があります**。最初に状態を確認してください。ブラウザーのタブを閉じても、サービスや取引プロセスは停止しません。

## 初めての利用：9 ステップ

1. **ガイドと状態を確認する。** `新手指南`（初心者ガイド）から `带我走一遍`（順に案内）を選びます。ガイドは説明のみです。読み取り専用か、戦略が稼働・復旧中かを確認します。
2. **API ウォレットを承認する。** 取引所の公式画面で独立した API ウォレットを資金口座に承認します。メインウォレットの秘密鍵は入力しないでください。取引権限だけでも損失につながる可能性があります。
3. **ウォレット情報を入力する。** `钱包与配置` で名前、資金口座アドレス、API ウォレット秘密鍵を入力します。資金口座は取引対象のメイン口座または承認済みサブ口座であり、**API ウォレットのアドレスではありません**。
4. **ローカルに保存する。** `保存本机配置` を押します。同じ名前は既存登録の更新です。登録済みアドレス・秘密鍵を空欄にすると元の値を保持します。別の資金口座には新しい名前を使います。保存だけで取引所の承認確認が完了するわけではありません。
5. **次回起動の予算を設定する。** 上部の `风险预算` で市場を選び、マーケットメイクの片側総額、最大ポジション、最大注文総額、セッションのドローダウンを入力します。`保存固定预算` は選択市場のエクイティ連動拡大を無効にします。稼働・復旧中は先に安全停止が必要です。
6. **戦略と開始範囲を確認する。** マーケットメイクは**有効な全ウォレットの設定済み全市場**、現在は SNDK と ANTH を開始します。予算の市場選択は開始範囲を絞りません。グリッドは選択したウォレットと市場だけを開始し、方向・段数・間隔・注文額・基準価格を別途設定します。既存の在庫や履歴がある場合、方向変更には制約があります。**在庫グリッドは実験的機能で、コードの実装とコードレベルのテストのみ完了しています。実取引テストは未実施であり、開始ボタンの存在は実取引での利用可能性の検証を意味しません。**
7. **確認後に実取引を判断する。** 資金口座、保有ポジション、未約定注文、使用可能証拠金、予算と方向を確認してから、実取引と明記されたボタンを押すか判断します。開始リクエストの受付は、事前確認や注文の成功を意味しません。
8. **状態、約定、ログを見る。** 次回設定と現在／前回の実績は別の情報です。エラーは内容を確認してから対処します。`UNKNOWN` は結果未確定であり、失敗とみなして再注文してはいけません。
9. **安全停止し、残るポジションを確認する。** `全部安全撤单并停止` を押し、完了後に取引所の状態を確認します。**注文取消と停止はポジション決済ではありません。** `flatten_on_halt` はリスク停止時の縮小動作に関する設定です。タブを閉じる、プロセスを強制終了する、台帳を削除するといった操作で代用しないでください。

## 予算と設定ファイル

予算は**選択市場の各有効ウォレット**に適用され、複数ウォレットで共有する合計額ではありません。片側予算は価格階段全体の金額で、各段の金額ではありません。グリッドの注文額は別設定です。ほかの 3 つの制限はその市場のグリッドにも適用されます。

公開例は各市場・各ウォレットにつき片側 `$12`、最大ネットポジション `$30`、最大注文総額 `$30`、セッションドローダウン `$3` です。確認用の小額テンプレートであり、推奨額や損失上限の保証ではありません。最低注文額や丸めの条件に適合しない場合もあります。自動拡大、API 操作枠の有料購入、未入金リベートの予測計上は初期状態で無効です。

| ファイル | 用途 |
|---|---|
| `config.example.json` | 秘密鍵を含まないペーパートレード例 |
| `config.json` / `config.market_maker.json` / `config.grid.json` | 公開 CLI 設定。初期値は `paper` |
| `dashboard.config.json` | 保存したローカル予算 |
| `dashboard.config.example.json` | ローカル予算ファイルがない場合の小額初期値 |
| `wallet.local.json` | GUI が保存する認証情報。形式は `wallet.example.json` を参照 |
| `.env` | 任意の単一ウォレット CLI 認証情報。`live.env_file` で明示した場合のみ読み込み |
| `state/` / `logs/` | 注文、約定、在庫、実行履歴。復旧のため保持する |

予算保存は次回起動値を即座に更新しますが、取引開始や履歴の書き換えは行いません。ほかの設定を手動編集した場合は安全停止後に関連プロセスを再起動してください。予算ファイルが両方ない、またはローカルファイルが壊れている場合はエラーにし、大額設定へ暗黙に戻しません。

名前付きウォレットは個別の JSON 認証情報を使います。`primary` ではプロセス環境変数、明示した `.env`、JSON の順に優先されるため、既存の環境変数に注意してください。画面にも案内が表示されます。`wallet1` など区別できる名前を推奨します。

## ペーパートレード、実取引、読み取り専用

```powershell
# 市場情報のみ確認
.\.venv\Scripts\python.exe main.py --config config.json --check

# ペーパートレード。実際の注文は送信しない
.\.venv\Scripts\python.exe main.py --config config.market_maker.json
.\.venv\Scripts\python.exe main.py --config config.grid.json

# 保存、取引操作、自動復旧を禁止する表示モード
.\.venv\Scripts\python.exe dashboard.py --port 8767 --read-only
```

`check_market.bat`、`run_market_maker.bat`、`run_grid.bat` も利用できます。ペーパートレードは実際の注文待ち順位、すべてのスリッページ、収益性を再現しません。**CLI の初期値が paper でも、通常ダッシュボードの開始ボタンは実取引です。**

実取引のサポート範囲は Windows です。Linux/macOS では paper または読み取り専用の自主検証に限定してください。署名者単位の同等なプロセス間ロックがないため、複数市場・プロセスで同じ API 署名ウォレットを共有する実取引はできません。Windows の機能確認も実約定や長期利益の認証ではありません。

## 秘密鍵、復旧、統計

- 秘密鍵は `wallet.local.json` または設定した `.env` に**ローカル平文**で保存されます。画面から保存済み秘密鍵を読み戻すことはありません。これらのファイル、`state/`、`logs/`、秘密鍵の画像、口座情報入りの診断資料を公開しないでください。公開設定には作者の口座や作者指定プロキシを含みません。
- 更新前に安全停止し、自分の設定・認証情報・状態をバックアップします。他人の台帳を使ったり、`UNKNOWN` や在庫不一致を回避するために記録を消したりせず、取引所の元注文とポジションを照合してください。
- グリッドのペア利益は口座純利益ではありません。実現価格損益から手数料を引いた値だけでは資金調達料、含み損益、入出金、未入金報酬を網羅できません。30 秒 markout は約定後の値動きであり、最終損失ではありません。欠損値をゼロ扱いしないでください。

```powershell
.\.venv\Scripts\python.exe analyze_efficiency.py --state-dir state --format table
.\.venv\Scripts\python.exe audit_local_data.py --output reports/local-data.json
```

## 任意の紹介リンク

[traderx のリンクで Entropy を開く](https://entropy.io/?r=traderx)

作者が確認した紹介特典は **Entropy が受け取る手数料分に対する 75%** であり、取引手数料全体の 75% ではありません。適用条件、実際の率、入金は公式アカウント画面と現行規則に従います。この説明で取引手数料率を変更したり、未入金報酬を実損益に加えたりすることはありません。

利用は任意です。プログラムは紹介関係の署名登録、既存紹介の変更、builder 手数料の追加を行いません。紹介特典と自身のティア特典は公式規則に従い高い方を適用し、加算しません。
