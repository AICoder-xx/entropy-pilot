# Entropy Pilot

**Entropy 양방향 마켓 메이킹, 실제 재고 기반 그리드 거래, 로컬 브라우저 대시보드.**

[简体中文](../../README.md) · [English](README.en.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · 한국어

Entropy Pilot은 사용자의 PC에서 실행하는 Python 도구입니다. `io:SNDK`와 `io:ANTH`를 지원하며 지갑 설정, 위험 예산, 전략 제어, 차트와 로그를 한 화면에서 제공합니다. **현재 대시보드 UI는 중국어입니다. 이 페이지는 문서 번역이며 UI 언어 전환 기능을 의미하지 않습니다.**

> 대시보드의 실거래 시작 버튼은 실제 주문을 전송합니다. 공개 CLI 설정의 기본값은 모의 거래입니다. 전략이나 추천 혜택은 수익을 보장하지 않습니다.

> **재고 그리드는 실험적 기능이며 아직 실거래 테스트를 거치지 않았습니다. 현재 완료된 범위는 코드 구현과 코드 수준 테스트뿐이며, 실거래에서 사용할 수 있는지 검증되었다는 뜻이 아닙니다.**

## 주요 기능

- **양방향 마켓 메이킹:** ALO/Maker 매수·매도 호가, 재고에 따른 조정, 포지션 및 주문 한도.
- **실제 재고 기반 그리드(실험적 기능):** 롱·숏 방향을 지원합니다. 청산 주문은 보유 재고를 줄이며, 매칭된 그리드 수익과 계정 손익을 구분합니다. 코드 구현과 테스트만 완료했으며 실거래 테스트는 수행하지 않았습니다.
- **여러 지갑과 시장:** 프로세스 및 주문·체결·복구 기록을 분리합니다.
- **로컬 제어:** 지갑 입력, 고정 예산 저장, 시작·안전 정지, 차트·로그 확인.
- **불확실한 주문 처리:** `UNKNOWN`을 유지하고 원래 주문을 대조한 뒤 다음 작업을 수행합니다.
- **9단계 안내:** 관련 영역을 강조하며 설명만 제공합니다. 설정 저장이나 주문 버튼을 대신 누르지 않습니다.

## Windows 빠른 시작

[Git](https://git-scm.com/downloads)과 [Python 3.11 이상](https://www.python.org/downloads/)을 설치하고 Windows Python Launcher(`py`)를 포함하세요. 이번 설치, 테스트, 브라우저 흐름은 **Windows / Python 3.13**에서 검증했습니다. 모의 거래에는 개인 키가 필요하지 않습니다. 실거래에는 자금 계정과 별도로 승인한 API 지갑이 필요합니다.

PowerShell에서 Git과 Python 3.13을 설치할 수도 있습니다.

```powershell
winget install --id Git.Git -e --source winget
winget install --id Python.Python.3.13 -e --source winget
```

`winget`을 사용할 수 없으면 위의 Git과 Python 공식 다운로드 링크를 이용하세요. 설치 후 **PowerShell을 닫고 다시 열어** 버전을 확인하고 프로젝트를 설정합니다.

```powershell
git --version
py -3.13 --version
git clone https://github.com/AICoder-xx/entropy-pilot.git
cd entropy-pilot
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe dashboard.py
```

[http://127.0.0.1:8765/](http://127.0.0.1:8765/)에 접속합니다. 가상 환경의 Python을 직접 호출하므로 `Activate.ps1` 실행이나 PowerShell 실행 정책 변경이 필요 없습니다. 소스를 내려받아 압축을 푼 뒤 `install.bat`, `run_dashboard.bat` 순서로 더블 클릭해도 됩니다.

`run_dashboard.bat` 또는 `dashboard.py`로 백엔드를 시작한 다음 위 주소를 여세요. `dashboard/index.html`을 직접 더블 클릭하면 백엔드에 연결할 수 없습니다. 읽기 전용 잠금이 걸린 것이 아니므로 정상 시작 경로로 다시 실행하세요.

일반 모드에서는 설정을 저장할 수 있습니다. 새 설치는 정지 상태지만, **기존 실행 디렉터리는 저장된 제어 상태에 따라 복구를 시작할 수 있습니다**. 먼저 실제 상태를 확인하세요. 브라우저 탭을 닫아도 서비스나 거래 프로세스가 정지하지 않습니다.

## 처음 사용하는 9단계

1. **안내와 상태를 확인합니다.** `新手指南`(초보자 안내) → `带我走一遍`(단계별 안내)을 선택합니다. 안내는 설명만 합니다. 읽기 전용인지, 실행 또는 복구 중인 전략이 있는지 확인하세요.
2. **독립 API 지갑을 승인합니다.** 거래소 공식 화면에서 자금 계정에 API 지갑을 승인하세요. 메인 지갑 개인 키를 입력하지 마세요. 거래 권한만 유출되어도 자금 손실이 발생할 수 있습니다.
3. **지갑 정보를 입력합니다.** `钱包与配置`에서 지갑 이름, 자금 계정 주소, API 지갑 개인 키를 입력합니다. 자금 계정 주소는 거래할 메인 계정 또는 승인된 하위 계정이며, **API 지갑 주소가 아닙니다**.
4. **로컬에 저장합니다.** `保存本机配置`를 누릅니다. 같은 이름은 기존 지갑을 갱신합니다. 이미 저장한 주소·키를 빈칸으로 두면 기존 값을 유지합니다. 다른 자금 계정에는 새 이름을 사용하세요. 저장이 거래소 승인 성공을 뜻하지는 않으며 시작할 때 다시 검사합니다.
5. **다음 실행 예산을 설정합니다.** 상단 `风险预算`에서 SNDK 또는 ANTH를 선택하고 편측 마켓 메이킹 총액, 최대 포지션, 최대 미체결 주문액, 세션 드로다운을 입력합니다. `保存固定预算`(고정 예산 저장)은 해당 시장의 자산 연동 자동 확대를 끕니다. 실행·복구 중에는 먼저 안전 정지해야 합니다.
6. **전략과 시작 범위를 확인합니다.** 마켓 메이킹은 **활성화된 모든 지갑의 설정된 모든 시장**, 현재 SNDK와 ANTH를 시작합니다. 예산 시장 선택은 시작 범위를 제한하지 않습니다. 그리드는 선택한 지갑과 시장만 시작하며 방향, 단계 수, 간격, 주문당 금액, 기준 가격을 별도로 설정합니다. 기존 재고나 이력이 있으면 방향 변경에 제한이 있습니다. **재고 그리드는 실험적 기능으로 코드 구현과 코드 수준 테스트만 완료했습니다. 실거래 테스트는 아직 수행하지 않았으며, 시작 버튼이 있다고 해서 실거래 사용 가능성이 검증된 것은 아닙니다.**
7. **확인한 뒤 실거래 여부를 결정합니다.** 자금 계정, 실제 포지션, 미체결 주문, 사용 가능한 증거금, 예산과 방향을 확인한 뒤 실거래로 표시된 버튼을 누를지 결정하세요. 시작 요청이 접수되어도 사전 검사나 호가 제출이 성공한 것은 아닙니다.
8. **상태, 체결과 로그를 확인합니다.** 다음 실행 설정과 현재·이전 실행 통계는 별개입니다. 오류가 발생하면 구체적인 안내부터 읽으세요. `UNKNOWN`은 결과가 불확실하다는 뜻이며, 실패로 간주해 주문을 다시 보내면 안 됩니다.
9. **안전 정지 후 남은 포지션을 확인합니다.** `全部安全撤单并停止`를 누르고 완료를 기다린 뒤 거래소 상태를 확인합니다. **호가 중단과 주문 취소는 포지션 청산이 아닙니다.** `flatten_on_halt`는 위험 중단 시 감축 동작만 제어합니다. 탭 닫기, 프로세스 강제 종료, 장부 삭제로 대신하지 마세요.

## 예산과 설정 파일

예산은 **선택한 시장의 각 활성 지갑**에 적용되며 여러 지갑이 공유하는 총액이 아닙니다. 편측 예산은 한쪽 호가 사다리 전체의 금액이지 단계마다 반복 적용하는 금액이 아닙니다. 그리드 주문당 금액은 별도이며 나머지 세 위험 한도는 해당 시장의 그리드에도 적용됩니다. 전체 지갑과 시장의 합산 노출을 고려하세요.

공개 예시는 지갑·시장별 편측 `$12`, 최대 순포지션 `$30`, 최대 미체결 주문액 `$30`, 세션 드로다운 `$3`입니다. 확인하기 쉬운 소액 템플릿이며 권장 배분이나 최대 손실 보장이 아닙니다. 거래소의 최소 주문액·수량 정밀도에 맞지 않을 수 있습니다. 기본값은 자동 확대, 유료 API 작업 한도 구매, 미입금 리베이트 예상 반영을 사용하지 않습니다.

| 파일 | 용도 |
|---|---|
| `config.json` | 기본 CLI 및 마켓 메이킹 모의 거래 설정. 개인 키는 포함하지 않음 |
| `config.grid.json` | 그리드 모의 거래 설정 |
| `config.live.example.json` | 대시보드가 읽는 실거래 템플릿. 인증 정보가 비어 있으므로 먼저 로컬 지갑을 설정해야 함 |
| `dashboard.config.json` | 저장한 로컬 대시보드 예산 |
| `dashboard.config.example.json` | 로컬 예산 파일이 없을 때 사용하는 소액 기본값 |
| `wallet.local.json` | GUI가 저장하는 로컬 인증 정보. 형식은 `wallet.example.json` 참고 |
| `.env` | 선택적인 단일 지갑 CLI 인증 파일. `live.env_file`로 명시할 때만 읽음 |
| `state/`, `logs/` | 주문·체결·재고·실행 기록. 복구를 위해 보존 |

예산 저장은 다음 실행 값을 즉시 갱신하지만 거래를 시작하거나 과거 통계를 변경하지 않습니다. 다른 파일을 수동으로 수정하면 먼저 안전 정지하고 관련 프로세스를 다시 시작하세요. 예산 파일이 둘 다 없거나 로컬 파일이 손상되면 오류를 표시하며 숨겨진 대규모 예산으로 돌아가지 않습니다.

이름이 있는 지갑은 각자의 JSON 인증 정보를 사용합니다. `primary`는 프로세스 환경 변수 → 명시한 `.env` → 로컬 JSON 순서이므로 기존 환경 변수의 영향을 받을 수 있습니다. 화면에도 안내가 표시됩니다. `wallet1`처럼 구분되는 이름을 권장합니다.

## 모의 거래, 실거래, 읽기 전용

```powershell
# 시장 데이터만 확인
.\.venv\Scripts\python.exe main.py --config config.json --check

# 모의 거래: 실제 주문 없음
.\.venv\Scripts\python.exe main.py --config config.json
.\.venv\Scripts\python.exe main.py --config config.grid.json

# 저장·거래 제어·자동 복구가 없는 읽기 전용 화면
.\.venv\Scripts\python.exe dashboard.py --port 8767 --read-only
```

`check_market.bat`, `run_market_maker.bat`, `run_grid.bat`도 사용할 수 있습니다. 모의 체결은 실제 주문 대기 순서, 모든 슬리피지나 수익성을 재현하지 않습니다. **CLI가 paper 기본값이어도 일반 대시보드의 시작 버튼은 실거래입니다.**

실거래 지원 범위는 Windows입니다. Linux/macOS에서는 paper 또는 읽기 전용 모드만 직접 검증하세요. 동일한 수준의 서명자별 프로세스 간 잠금이 없어 여러 시장·프로세스가 하나의 API 서명 지갑으로 실거래하면 안 됩니다. Windows 기능 검증도 실제 체결이나 장기 수익 인증은 아닙니다.

## 개인 키, 복구와 통계

- 개인 키는 `wallet.local.json` 또는 직접 지정한 `.env`에 **로컬 평문**으로 저장됩니다. 화면은 저장된 키를 다시 반환하지 않습니다. 이 파일들, `state/`, `logs/`, 키 스크린샷, 계정 정보가 담긴 진단 자료를 공개하지 마세요. 공개 설정에는 작성자 계정이나 작성자 프록시 주소가 없습니다.
- 업데이트 전 안전 정지하고 자신의 설정·인증 정보·상태를 백업하세요. 다른 사람의 장부를 가져오거나 `UNKNOWN`, 재고 충돌, 늦은 체결을 우회하려고 기록을 삭제하지 마세요. 거래소의 원래 주문과 포지션을 먼저 대조해야 합니다.
- 그리드 매칭 수익은 계정 순이익과 다릅니다. 실현 가격 손익에서 수수료를 뺀 값만으로는 펀딩비, 미실현 손익, 입출금, 미입금 보상을 모두 포함할 수 없습니다. 30초 markout은 체결 이후 가격 움직임이며 최종 손실이 아닙니다. 누락된 값은 0이 아닙니다.

```powershell
.\.venv\Scripts\python.exe analyze_efficiency.py --state-dir state --format table
.\.venv\Scripts\python.exe audit_local_data.py --output reports/local-data.json
```

## 선택적인 추천 링크

[traderx 링크로 Entropy 열기](https://entropy.io/?r=traderx)

작성자가 확인한 추천 혜택은 **Entropy가 받는 거래 수수료 몫의 75%**이며, 전체 거래 수수료의 75%가 아닙니다. 실제 자격, 비율과 지급은 공식 계정 화면 및 현행 규칙을 따릅니다. 이 설명이 거래 수수료율을 바꾸거나 미입금 보상을 실제 손익에 더하지는 않습니다.

링크 사용은 선택 사항입니다. 프로그램은 추천인 연결에 자동 서명하거나 기존 추천 관계를 변경하지 않고 builder 수수료도 추가하지 않습니다. 추천 혜택과 개인 등급 혜택은 공식 규칙에 따라 더 높은 쪽을 적용하며 중복 합산하지 않습니다.
